# Changelog

## 1.0.0 — 2026-11-04

First stable Starter release.

- GitHub template with an explicit offline `demo` and separate `live` public-page entry point.
- Five frozen tools, source hashes, original licenses and 17 deterministic fictional report files.
- Scope brief, observation/decision registers and approved-input guidance.
- GitHub verification and manual live-observation workflows consuming an immutable Action commit.
- French quick-start guide, original social preview and recorded browser walkthrough.

No live LLM-answer collection, ranking score or automated factual verification is included. The fictional workflow is kept separate from real observations.
